📚 API 对接教程

本教程将帮助你快速接入 MiniMax API 服务，只需几分钟即可完成集成

🚀 快速开始
1
获取 API Key

联系平台管理员获取你的专属 API Key，或访问 用量查询 页面测试。

2
查看支持的模型

平台支持多种 MiniMax 模型，选择适合你业务的模型即可。

3
开始调用

使用下方任意代码示例发起请求，享受 MiniMax 强大的人工智能能力。

🌐 API 地址
POST https://tools.imoons.cn/mini/v1/chat/completions
💡 提示：所有请求必须使用 HTTPS 协议，HTTP 请求会被拒绝。
🔐 认证方式

在 HTTP 请求头中添加你的 API Key：

X-Api-Key: your-api-key-here

cURL 示例

curl -X POST https://tools.imoons.cn/mini/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: your-api-key-here" \
  -d '{
    "model": "MiniMax-M2.7",
    "messages": [{"role": "user", "content": "你好"}]
  }'
📤 请求格式
{
  "model": "MiniMax-M2.7",
  "messages": [
    {"role": "system", "content": "你是一个有帮助的AI助手"},
    {"role": "user", "content": "你好，请介绍一下自己"}
  ],
  "temperature": 0.7,
  "max_tokens": 1000
}
参数
类型
说明
model
string
模型名称，必填。见下方模型列表。
messages
array
消息数组，包含 role 和 content，必填。
temperature
float
采样温度，0-2 之间，越高越有创造性。
max_tokens
int
最大生成 token 数，控制回复长度。

💻 代码示例

Python

import requests

url = "https://tools.imoons.cn/mini/v1/chat/completions"
headers = {
    "Content-Type": "application/json",
    "X-Api-Key": "your-api-key-here"
}
data = {
    "model": "MiniMax-M2.7",
    "messages": [
        {"role": "user", "content": "用 Python 写一个快速排序"}
    ],
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
print(response.json())

JavaScript / Node.js

const response = await fetch('https://tools.imoons.cn/mini/v1/chat/completions', {

console.log(data.choices[0].message.content);

Go

package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    url := "https://tools.imoons.cn/mini/v1/chat/completions"
    
    data := map[string]interface{}{
        "model": "MiniMax-M2.7",
        "messages": []map]string{
            {"role": "user", "content": "用 Go 写一个快速排序"},
        },
    }
    
    jsonData, _ := json.Marshal(data)
    
    req, _ := http.NewRequest("POST", url, bytes.NewBuffer(jsonData))
    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("X-Api-Key", "your-api-key-here")
    
    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
}

⚠️ 错误码说明
401 API Key 无效、被禁用或已过期
429 请求过于频繁，已达到每日/每月调用限额
500 服务器内部错误，稍后重试
502 上游 MiniMax 服务异常，联系管理员
💡 最佳实践

1. 错误处理

总是检查响应中的错误字段，并设置合理的重试机制：

if (response.status !== 200) {
    console.error('API Error:', response.data.error);
    // 重试逻辑
}

2. 会话管理

将 messages 数组作为会话上下文，实现多轮对话：

messages = [
    {role: "system", content: "你是一个专业顾问"},
    {role: "user", content: "第一个问题"},
    {role: "assistant", content: "第一个回答"},
    {role: "user", content: "追问第一个回答"}  // 带上下文
]

3. 合理设置 max_tokens

根据实际需求设置，避免浪费 token 或回复被截断。
